# Stamp2Go – גשר מקומי בין הזמנות באתר למחשב CorelDRAW/מדפסת

## מה קיים בענף הבדיקה
- API לקריאה בלבד (Bearer ייעודי) להזמנות שאושרו ומוכנות לייצור; מחזיר קובץ PDF וקטורי שנוצר באתר.
- סוכן Python 3.10+ ל-Windows: בודק עבודות כל 30 שניות, מוריד PDF, יוצר קובץ JSON עם מידות במ"מ, כמות, Mirror ומזהי עבודה.
- מניעת הורדות ושליחות כפולות באמצעות SQLite מקומי וזיהוי גרסת עיצוב. אחרי שליחה מסופקת למתאם או שגיאה לא-ודאית, הוא לא ישלח שוב אוטומטית.
- מצב ברירת מחדל: הכנת קבצים לתיקייה בלבד — **לא מפעיל את Corel או המדפסת**.
- נקודת שילוב למתאם מקומי לגרסת Corel הישנה ולמדפסת. יש לבנות/לאמת מתאם ספציפי רק לאחר זיהוי דגם וגרסה.

## תהליך העבודה
הזמנה באתר → אישור תשלום/הגהה → מנוע קבצי ייצור → READY_FOR_PRODUCTION
→ API /api/print-agent/jobs/ → סוכן מקומי → /api/print-agent/files/
→ PDF + כרטיס ייצור JSON במחשב הסטודיו → מתאם Corel מקומי שנבדק → מדפסת.

מיילי ההזמנה הקיימים ממשיכים לעבוד; אין צורך *לסרוק מייל* כשמדובר בהזמנה מאתר Stamp2Go עצמו. הזמנה חיצונית שמגיעה **רק** במייל דורשת בהמשך קליטת דוא"ל נפרדת, אימות שולח/קבצים ומניעת כפילות.

## הכנה בטוחה
1. לפרוס את הענף לסביבת Preview עם נתוני בדיקה ומסד נתונים נפרד, ולא לחבר למדפסת אמתית בשלב הראשון.
2. להגדיר בצד השרת PRINT_AGENT_TOKEN: מפתח אקראי של 32 תווים לפחות. לא לשמור סוד ב-Git.
3. להשאיר PRINT_AGENT_ALLOW_UNPAID_MANUAL=false (ברירת מחדל). הזמנות באיסוף/תשלום ידני לא יישלחו לפני ששולמו אלא אם מאפשרים זאת במכוון.
4. במחשב Windows של הסטודיו להתקין Python 3.10 ומעלה, ולהעתיק אליו את scripts/print_agent.py.
5. להריץ ב-PowerShell (לשנות דומיין ומפתח):

~~~powershell
$env:STAMP_SITE_URL = 'https://your-staging-domain.example'
$env:STAMP_PRINT_AGENT_TOKEN = '<same-secret-as-PRINT_AGENT_TOKEN>'
$env:STAMP_PRINT_DIR = 'C:\Stamp2Go\Production'
python .\scripts\print_agent.py --once
~~~

6. לוודא שבתיקייה מופיעים PDF ו-JSON לכל פריט בהזמנה המאושרת. לבדוק פתיחה ב-Corel הישן, מידות 1:1, כמות, קווים, פונטים מומרים לעקומות, כיוון, Mirror, חיתוך, דיו ומאפייני הדרייבר.
7. לבחון לפחות חמש חותמות ייצור אמיתיות לפי docs/PRODUCTION.md לפני כל שליחה אוטומטית למכונה.

## עבודה רציפה
להריץ ללא --once כדי שהסוכן יבדוק תור כל 30 שניות. אפשר להפעילו אוטומטית עם Windows Task Scheduler כשמשתמש הייצור נכנס למחשב. הסוכן חייב לרוץ על מחשב הסטודיו, לא על Vercel.

## מתאם הדפסה (כבוי כברירת מחדל)
לאחר שפותח ונבדק מתאם מקומי לגרסת Corel ולמכונה, אפשר להגדיר פקודת הדפסה בלי shell, עם משתני ארגומנטים: {file}, {copies}, {width_mm}, {height_mm}, {mirror}, {metadata}, {job_id}. חובה להשתמש ב-{file} וב-{copies}. דוגמה בלבד — קובץ CorelPrintAdapter.exe **עדיין לא קיים בפרויקט**:

~~~powershell
$env:STAMP_PRINT_MODE = 'command'
$env:STAMP_PRINT_COMMAND_JSON = '["C:\\Stamp2Go\\CorelPrintAdapter.exe", "{file}", "{copies}", "{width_mm}", "{height_mm}", "{mirror}"]'
$env:STAMP_ENABLE_REAL_PRINT = 'YES_I_TESTED_IT'
python .\scripts\print_agent.py --once
~~~

קוד חזרה 0 מהמתאם פירושו שהתקבלה הפקודה, לא שהדפסה פיזית הושלמה. יש לבצע אימות מדפסת/אישור עובד ולסגור עבודה במערכת הניהול.

## מגבלות
- אין שינוי בנתיב התשלום, בתור הייצור, במיילי האתר או במדפסת הקיימת.
- ה-API הוא לקריאה בלבד: לא מסמן הזמנה כהודפסה, לא נועל אותה אצל סוכנים אחרים. להריץ סוכן אחד בלבד. הרחבה לכמה עמדות מחייבת claim/lease אטומי ו-ack מרכזי.
- מצב 'submitted' או 'submitting' נשמר מקומית. כאשר גורל העבודה לא ברור, הסוכן נמנע משליחה חוזרת: אישור/שחזור נעשה ידנית.
- נדרש מסד נתונים עמיד (Neon או Supabase). אחסון זמני גורר 503.
- רשימת התור מוגבלת ל-2,000 הזמנות מוכנות לייצור בכל משיכה, ומחזירה עד 100 עבודות; לפעילות מפעל גדולה דרוש מנגנון דפדוף.
- הסוכן אינו ממיר CDR ישן, אינו שולח פקודת הדפסה ישירות ל-Corel ואינו קולט דוא"ל חיצוני בשלב זה. אין להפעיל מצב הדפסה אמתית בלי גרסת Corel, דגם המכונה ודוגמת CDR.
- יש להגן על המפתח, תיקיית הייצור והמחשב המקומי.

## בדיקות לפני הפעלה אמתית
תשלום שטרם אושר; ממתין להגהה; PDF פגום; מסמך שעבר שינוי; הזמנה כפולה; שני פריטים; כמויות; נפילת אינטרנט; קריסה בזמן שליחה; שיקוף ו-Negative; מידות במ"מ; משוב מדפסת.
